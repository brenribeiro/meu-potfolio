# Portfólio — Desenvolvedor(a) Front-end

Portfólio responsivo feito com React, Vite e CSS Modules. A página reúne apresentação profissional, projetos, habilidades e formas de contato, com navegação por âncoras e menu adaptado para dispositivos móveis.

> **Antes de publicar:** o conteúdo atual é demonstrativo. Troque “Seu Nome”, o texto de apresentação, o e-mail, as redes sociais, a foto e os projetos pelos seus dados reais. Os links de repositório e demonstração usam `SEU_USUARIO` como marcador e precisam ser atualizados.

## Projetos apresentados

- **Organiza:** painel de tarefas com React, CSS Modules e armazenamento local.
- **CineBusca:** catálogo de filmes com busca e consumo de API REST.
- **DevLinks:** página de links pessoais em HTML, CSS e JavaScript.

Os projetos e as prévias visuais são exemplos para personalização; não representam repositórios ou aplicações publicados.

## Executar localmente

Requisitos: Node.js 18 ou superior e npm.

```bash
npm install
npm run dev
```

Abra o endereço local mostrado pelo Vite no terminal. Para verificar a versão de produção:

```bash
npm run build
npm run preview
```

## Publicação

O projeto pode ser publicado gratuitamente na Vercel, Netlify ou GitHub Pages. Para Vercel ou Netlify, importe o repositório e mantenha os padrões:

- **Comando de build:** `npm run build`
- **Diretório de saída:** `dist`

**Portfólio online:** ainda não publicado. Adicione aqui o endereço após fazer o deploy.

## Personalização

- Edite o conteúdo, habilidades e projetos em `src/App.jsx`.
- Atualize nome, e-mail e redes sociais também em `src/App.jsx` e `index.html`.
- Substitua o bloco de retrato da seção Sobre por uma foto sua.
- Ajuste a identidade visual e os breakpoints em `src/App.module.css`.
